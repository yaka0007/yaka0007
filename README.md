**[Mnemosyne OS](https://github.com/Mnemosyne-OS/Mnemosyne-Neural-OS)** is a local-first
memory operating system for one human. Your files and conversations become durable,
searchable memory that any model you connect can draw on. Vaults live on your hardware,
encrypted at rest under a key only you hold. Windows, macOS and Linux.

The 77.1% above is LongMemEval-M, full haystack, strict judge. The kit behind the badge
lets you replay the run and check every verdict yourself.
